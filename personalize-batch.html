Agent skill and batch instructions

Enumerate the wallet's Squares

Use Ethereum mainnet (chain ID 1). The Su Squares ERC-721 contract is 0xE9e3F9cfc1A64DFca53614a0182CFAD56c10624F. Call balanceOf(address owner) returns (uint256) to get the wallet's balance. For every index from 0 through balance minus 1, call tokenOfOwnerByIndex(address owner, uint256 index) returns (uint256). These return Square IDs from 1 to 10000. Do not assume the IDs are consecutive. Before submitting, verify ownerOf(uint256 tokenId) returns (address) matches the connected wallet for every Square.

This page loads the first 20 owned Squares for you after connecting. Click Load more for the next 20, and repeat until all are listed. You can submit any Squares you own, including ones not yet listed.

Prepare the text and RGB data

Paste one Square per line, with exactly four tab-separated columns, no header: Square number[TAB]Title[TAB]Link[TAB]0xRRGGBB.... You can copy to and from a spreadsheet. Do not include tabs or line breaks inside a title or link, or repeat a Square number.

Square numbers must be whole numbers from 1 to 10000. Titles must be 1–64 UTF-8 bytes and links 1–96 UTF-8 bytes, not character counts. Links typically start with https://.

Each Square's image is exactly 10×10 opaque pixels. Encode each pixel as two hex digits for red, two for green and two for blue, in row-major order: top-left first, left to right, then the next row. Include all 100 pixels, giving 300 bytes: 0x followed by exactly 600 hexadecimal digits (602 characters total). No alpha channel, spaces, animation or image-file headers. For example, a solid red Square uses 0x followed by ff0000 repeated 100 times.

For larger artwork, split it into 10×10 tiles. A Square's zero-based column is (id - 1) % 100 and its row is floor((id - 1) / 100). The Square to the right is ID + 1 (unless at the right edge), and the Square below is ID + 100. Only include tiles the wallet owns.

Validate and confirm

Paste the prepared rows into the text box below, then click Validate. The page checks the format and on-chain ownership of every row. Any edit or wallet change requires validation again. Review the number of Squares and total price, then click Personalize and approve the transaction in your wallet.

The underlay contract is 0x992bDEC05cD423B73085586f7DcbbDaB953E0DCd. It accepts personalizeSquareUnderlayBatch((uint256 squareId, bytes rgbData, string title, string href)[] personalizations), payable with exactly 1000000000000000 wei per Square. Gas is additional. Submit the validated rows as tuples in that order. Never request or share a seed phrase or private key.
